# About

TradePro Analytics Suite is a professional trading analytics platform developed by **Dezprox LLP** for analyzing market data through multiple technical indicators and real-time calculations.

The application provides live market monitoring, Open Interest analysis, technical indicators, historical data analysis, Excel reporting, and configurable trading dashboards for market decision support.

The platform is designed with a modular architecture, allowing additional analytics modules to be integrated without affecting existing functionality.
